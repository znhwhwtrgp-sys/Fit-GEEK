FIT-GEEK — DARK LUXURY VISUAL REDESIGN
======================================

Dieses Paket enthält die bestehende Fit-GEEK-PWA mit einer deutlich überarbeiteten
mobilen Benutzeroberfläche: Brandbar, feste untere Navigationsleiste, Editorial-Startbereich mit gespeicherten Kleidungsfotos, Typografie, Karten, Raster,
Formulare, Outfit-Ansichten und Home-Schnellzugriffe im Schwarz-/Champagnergold-Stil.

WICHTIG
- Die bestehende JavaScript-Logik wurde beibehalten.
- IndexedDB bleibt `kleiderschrank`; die App-Datenbank wird nicht gelöscht.
- Das Redesign ist kein Screenshot: Kleidungsbilder stammen weiterhin aus deinen
  gespeicherten Fotos. Die Oberfläche nutzt vorhandene App-Funktionen.
- Vor dem Upload eine Sicherung deines Repositorys anlegen.
- GitHub Pages: Dateien aus diesem Ordner ins Repository-Hauptverzeichnis hochladen
  und gleichnamige Dateien ersetzen.
- Nach erfolgreicher Veröffentlichung zuerst die URL im normalen Browser öffnen.
  Keine Browserdaten löschen und die PWA nicht deinstallieren.

Dateien: index.html, manifest.webmanifest, sw.js, Icons.
