# Fit-GEEK – Dark Luxury Design Assets

This package contains a refreshed app icon and a CSS theme patch for the existing Fit-GEEK PWA.

## Included
- `icons/icon-192.png` – PWA icon (192 × 192)
- `icons/icon-512.png` – PWA icon (512 × 512)
- `icons/apple-touch-icon.png` – iOS home-screen icon (180 × 180)
- `dark-luxury-theme.css` – optional theme patch
- `GITHUB-INSTALLATION.md` – installation steps

## Important
This is an asset/theme package, not a replacement for your app's `index.html`.
Keep your existing JavaScript, IndexedDB setup, and app files so saved wardrobe items and outfits remain intact.
